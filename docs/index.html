최근 발행

버전 되돌리기

되돌리는 것은 봇 로직뿐이다. 발행 이력 DB·탭 캐시·이 콘솔·인수인계 문서는 그대로 둔다 — DB 를 되돌리면 이미 발행한 뉴스를 처음부터 다시 뿌리고, 탭 캐시를 되돌리면 텔레그램에 탭이 중복 생성된다.
누르면 도는 루프를 취소하고 그 버전으로 되돌린 뒤 봇을 새로 띄운다. 되돌린 것도 새 커밋이라 이력은 앞으로만 흐른다 — 다시 최신으로 오는 것도 같은 버튼이다.
